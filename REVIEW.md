## Items Examined and Decided NOT to be Defects

1. **`python-dotenv` without `override=True`:** `load_dotenv()` in `app/main.py` is called with default `override=False`. This is correct: real environment variables already set in the OS/container take precedence over local `.env` definitions, strictly satisfying Section 4 of the problem statement.
2. **MongoDB Lack of Relational Foreign Keys:** MongoDB does not enforce relational foreign key constraints between `attendance_logs.emp_code` and `employees.emp_code`. This is standard document database behavior, not a defect. Foreign key validation must be handled at the application level (e.g., verifying employee existence before creating or updating records).
3. **Absence of Graceful Shutdown:** While connection cleanup is a general best practice, neither `PROBLEM_STATEMENT.docx` nor `openapi.yaml` mandates graceful shutdown hooks.
